# 便携式三端 AI 工程知识库

**项目类型：个人 AI 工程效率系统 / 知识管理与本地 AI 应用**
**项目周期：2026年9月17日-22日**

## 项目简介

针对个人在公司电脑、家庭电脑及其他设备之间进行 Python、LLM、ComfyUI 与 AI 项目学习开发时存在的环境不统一、知识分散、代码与笔记难以同步等问题，设计并搭建了一套基于**移动硬盘 + Git + Obsidian + VSCode + Ollama + AnythingLLM**的便携式三端 AI 知识库系统。

系统将知识管理、代码管理、本地AI能力和便携式开发环境进行统一整合，实现学习资料、Markdown笔记、Python代码及AI项目资料的集中管理，并通过 Git 完成多设备版本同步。

## 系统架构

```text
                 移动硬盘 AI-Workspace
                         │
        ┌────────────────┼────────────────┐
        │                │                │
     Obsidian          VSCode          Ollama
        │                │                │
     知识管理          代码开发          本地AI
        │                │                │
        └──────────────┬─┴────────────────┘
                       │
                 knowledge-base
                       │
                 Git版本管理
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       电脑A         电脑B         电脑C
          │            │            │
        push          pull         pull
          └────────────┼────────────┘
                       ↓
                 Git远程仓库
```

## 核心功能

### 1. 便携式开发环境

将 Git、VSCode、Obsidian、Python、Ollama 等工具统一规划到移动硬盘工作区，减少不同电脑之间的环境差异，并降低在受限电脑环境中进行部署的成本。

### 2. 三端知识同步

以 Git 作为核心版本管理工具，将知识库作为 Git Repository 进行管理。

通过：

```text
电脑A
 ↓
git push
 ↓
远程Git仓库
 ↓
git pull
 ↓
电脑B / 电脑C
```

实现多设备之间的学习笔记、代码和项目资料同步，同时保留版本记录。

### 3. 结构化知识管理

使用 Obsidian 管理 Markdown 知识资产，并按照学习与工作方向进行分类：

```text
knowledge-base
├── 00_Inbox
├── 01_Python
├── 02_LLM
├── 03_ComfyUI
├── 04_AI影视制作
├── 05_字字动画插件
├── 06_项目记录
├── 07_技术踩坑
└── README.md
```

形成从学习笔记、技术踩坑、项目记录到代码资产的统一知识体系。

### 4. 本地 AI 知识库

使用 Ollama 提供本地大模型能力，并规划使用 AnythingLLM 对知识库进行索引，使 Markdown、PDF、TXT及代码资料能够进入本地 AI 检索流程。

实现：

```text
个人知识库
     ↓
文档解析
     ↓
向量化 / 检索
     ↓
本地LLM
     ↓
AI问答与知识辅助
```

### 5. 开发与知识联动

通过 VSCode 管理 Python 代码及插件项目，将学习过程中形成的知识、代码实践和项目开发进行关联，实现：

```text
学习理论
 ↓
Markdown笔记
 ↓
VSCode代码实践
 ↓
项目开发
 ↓
技术问题记录
 ↓
AI辅助复盘
 ↓
沉淀进知识库
```

形成持续迭代的个人 AI 工程学习闭环。

### 6. 一键启动

设计 `start.bat` 启动脚本，将工作区中的 Obsidian、VSCode 和 Ollama 等环境统一启动。

插入移动硬盘后即可进入统一工作环境，降低多设备切换成本。

## 项目难点与解决思路

### 便携环境与AI依赖冲突

早期尝试使用 Khoj 构建本地 AI 知识库时，遇到 Python 依赖复杂以及 `llama-cpp-python` 编译环境要求较高等问题。

经过分析后，将系统进行重新拆分：

**知识管理 → Obsidian**
**代码管理 → VSCode**
**版本同步 → Git**
**本地模型 → Ollama**
**AI知识检索 → AnythingLLM**

通过降低组件之间的耦合，避免将所有功能集中在单一知识库软件中。

### 公司电脑环境限制

针对公司电脑可能存在管理员权限、编译环境、网络环境等限制，将工作环境设计为移动硬盘便携式架构，尽可能降低对主机系统环境的依赖。

通过将“知识管理 + 代码管理 + 版本控制 + 本地模型 + AI检索 + 便携环境”进行模块化组合，实现个人 AI 学习与研发环境的长期积累与持续迭代。
