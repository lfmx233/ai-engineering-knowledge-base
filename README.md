# ai-engineering-knowledge-base
便携式三端 AI 工程知识库｜个人技术项目  针对三台电脑、公司电脑受限及移动硬盘便携需求，设计并搭建基于 Git + Obsidian + VSCode + Ollama + AnythingLLM 的个人 AI 知识库系统。 将 Python、LLM、ComfyUI、AI影视制作、项目代码及技术踩坑统一纳入 Markdown 知识体系，并通过 Git 实现多设备版本同步。 搭建 本地LLM + AI知识库 架构，使个人知识资料能够进入 AI 检索与问答流程，为后续 RAG、Agent 学习与开发提供基础环境。 通过便携式软件环境与一键启动脚本降低多设备环境配置成本，形成“学习 → 笔记 → 编程 → 项目 → AI复盘 → 知识沉淀”的个人 AI 工程工作流。
